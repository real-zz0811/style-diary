# 截图目录

仓库首屏（根目录 `README.md`）引用了这里的 4 张图。当前放的是**占位 SVG**（能正常渲染，不会裂图）。

## 换成真实截图（3 步）

1. 用手机打开线上地址，截 3 张竖屏图：衣橱 / 搭配工坊 / 灵感墙；再截 1 张合成出来的搭配长图。
2. 按下面的文件名存成 **PNG**，放进本目录：

   | 文件名 | 内容 | 建议比例 |
   |---|---|---|
   | `01-wardrobe.png` | 衣橱（有几件单品时截） | 竖屏，约 9:19.5 |
   | `02-outfit-workshop.png` | 搭配工坊（槽位已填 + 下方有历史记录） | 竖屏 |
   | `03-inspiration-wall.png` | 灵感墙（有备注文字时截） | 竖屏 |
   | `04-composite-long-image.png` | 点开历史搭配灯箱里的长图 | 竖屏，长图 |

3. 回到根目录 `README.md` 的「界面」一节，把 4 处 `.svg` 改成 `.png` 即可（本目录的 SVG 可一并删除）。

> 💡 截图前建议：先上传 4~6 件单品、合成 2~3 套搭配、灵感墙放 3~4 张图，画面才有信息量。
> 💡 如果没有 PNG，也可以用 `screencapture` / 手机录屏转 GIF，替换后把 `<img>` 换成 `<img src="...gif">` 同样可用。
